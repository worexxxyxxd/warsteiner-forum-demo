# Варштайнер Форум — демо-концепт сайта

Неофициальный демо-концепт многостраничного сайта для ресторана «Варштайнер Форум» (Невский пр., 120, Санкт-Петербург).
Сделан как предложение ресторану. Форма бронирования демонстрационная и никуда данные не отправляет.

Страницы: главная с 3D-заставкой, меню, бар, галерея, события, бронь со схемой зала, контакты.

Библиотеки: Three.js, GSAP + ScrollTrigger, Lenis, Leaflet (карта OpenStreetMap), Flatpickr.
